# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. The canonical text at that link governs; it is referenced rather than copied so it stays current.

In short:

- Participate respectfully. Critique code and claims, not people.
- Keep technical disagreement technical, specific, and evidence based.
- Harassment, personal attacks, and unwelcome private contact are not tolerated.
- Maintainers may edit, remove, or reject any contribution, issue, or comment that conflicts with the covenant.

## Reporting

Report a concern privately to the repository owner through GitHub, or open a [private security advisory](https://github.com/wolfiesch/omp-best-of/security/advisories/new) if a public report would expose sensitive information. Reports are handled confidentially, and a response should be expected within seven days.
